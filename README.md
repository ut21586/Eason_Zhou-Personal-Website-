# 周奕霖 Eason Zhou · Personal Website

周奕霖（Eason Zhou）的个人网站，单个 `index.html` 文件，无需构建，可直接用 GitHub Pages 发布。

- 中英文切换（右上角按钮）
- 页面：首页、经历、项目、技能、联系
- 背景：天秤座星座与星云动态效果

## 本地预览

直接用浏览器打开 `index.html`。

## 用 GitHub Pages 发布

仓库 Settings → Pages → Build and deployment → Source 选择 “Deploy from a branch”，Branch 选 `main`、目录 `/ (root)`，保存后几分钟即可访问。
